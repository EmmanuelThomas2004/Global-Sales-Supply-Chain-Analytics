# Power BI Report

This folder contains the complete Power BI report developed for the Global Sales & Supply Chain Analytics project.

The report transforms the analytical results generated through Snowflake and SQL into interactive business dashboards covering sales, profitability, customers, markets, and supply chain performance.

## Files

- `Global_Sales_Supply_Chain_Analytics.pbix` — Complete Power BI project file.
- `Global_Sales_Supply_Chain_Analytics.pdf` — Exported version of the five dashboard pages for quick viewing.

## Dashboard Pages

1. Global Supply Chain Performance Dashboard
2. Sales & Profit Analysis Dashboard
3. Customer & Market Performance Dashboard
4. Supply Chain & Delivery Analytics Dashboard
5. Key Insights & Strategic Recommendations Dashboard

## Purpose

The Power BI report provides a visual and business-focused layer for the project, enabling analysis of key performance indicators, sales and profit trends, customer and market performance, and supply chain delivery patterns.

Individual dashboard images are available in the `dashboard` folder of this repository.
